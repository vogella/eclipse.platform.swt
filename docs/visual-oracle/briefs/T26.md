## Your task: fix all three root causes

**1. The settle bound rejects a stable rendering (CHECK 14 and CHECK 56, one cause).**

Read that message carefully. It reports **one** distinct rendering, held for 19750 ms of a 20000 ms budget, and then calls the specimen non-deterministic. One distinct rendering that held for essentially the whole budget is the definition of stable. The logic appears to require the hold to reach the full budget, which the final grab makes impossible, so a perfectly stable cheap-to-render widget can never satisfy it.

Fix the condition so that a rendering which is the only value seen, and which held for the observation window, settles. Do not simply enlarge the budget: that hides the bug and makes every run slower. Prove the fix on `label.separator.horizontal` specifically, and prove that a genuinely animated fixture still fails (the existing `lint-animated-specimen-fails-despite-retry` check must stay green and must not be weakened).

**2. The classifier lost a case (CHECK 48).**

`diff-missing-element-classified` passed when T07 merged and now returns UNKNOWN for a removed rectangle. Something merged afterwards changed the captures the synthetic pair is built from. Find what actually changed rather than loosening the classifier: if the classifier is right and the fixture is now wrong, fix the fixture and say so.

**3. The zoom-200 measurement is fragile (CHECK 62).**

This check measured `native content 82x20 vs skia content 36x10, ratio 2.28` when T11 was verified an hour ago. It now measures `320x50 vs 320x34`, both spanning the full image width, so the ratio collapses to 1.00. The content-box detection is saturating, most likely because it is measuring a different specimen or a background that fills the frame.

The underlying defect it exists to catch is real and confirmed by eye: PR 3231's Skia canvas renders at roughly half size on a 200 percent display while the native canvas scales correctly. Make the measurement robust so it keeps catching that, rather than deleting or weakening the check.
